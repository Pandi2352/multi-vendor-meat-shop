# multi-vendor-meat-shop

A hyperlocal, multi-vendor meat ordering marketplace for Tamil Nadu.

| Folder    | App                                   |
| --------- | ------------------------------------- |
| `server/` | NestJS + MongoDB REST API with Swagger |
| `public/` | Customer storefront (React + Vite)    |
| `admin/`  | Vendor, admin and delivery portals    |
| `docs/`   | Project plan and reusable checklist   |

- Plan: [`docs/PROJECT_PLAN.md`](docs/PROJECT_PLAN.md)
- Shared building blocks: [`docs/REUSABLE_CHECKLIST.md`](docs/REUSABLE_CHECKLIST.md)
- Rules for contributors and AI agents: [`AGENTS.md`](AGENTS.md)

Requires Node `20.19.4` (see `.nvmrc`) and a local MongoDB.
